# Book Finder (iOS) — SwiftUI

## Overview
A simple SwiftUI app that uses the Open Library API to search books by title, show results with pagination, pull-to-refresh, and a details screen with a rotation animation of the cover. Books can be saved to Core Data as favorites.

## Requirements
- Xcode 13+ (project targets iOS 14.0+)
- Swift 5+
- Internet connection to call Open Library APIs.
